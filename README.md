A historical Perl module I created in 2003 for detecting heavily distorted German address variations.
This repository exists as a conceptual example of how I approach complex, adversarial problems.

## About AFT
AFT normalizes German address data across optical, phonetic, syntactic and semantic distortions
to detect the same person behind thousands of manipulated inputs.

This is not maintained software. It is published for historical and educational purposes only.
